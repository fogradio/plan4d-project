## ADDED Requirements

### Requirement: 候选场景预览与选择
系统 SHALL 在两个对比区复用独立的候选预览按钮和同一图片弹窗，保持原场景选择入口与实验资产不变。

#### Scenario: 预览不修改对比状态
- **WHEN** 用户点击放大按钮或使用前后按钮、左右方向键浏览
- **THEN** 仅更新当前区块候选的高清图、完整动作文本与编号，不选择场景、不加载其他候选点云、不重置基线或相机。

#### Scenario: 从预览确认选择
- **WHEN** 用户点击 Select This Scene
- **THEN** 关闭弹窗并调用该区块已有选择入口；重复选择当前场景不重新初始化。

#### Scenario: 可访问关闭与正常放大
- **WHEN** 用户使用 Tab、Shift+Tab、Escape、关闭按钮或背景
- **THEN** 所有可用弹窗控件可达，关闭后焦点返回触发按钮且选择不变；原图片放大入口不显示候选导航或选择按钮。

#### Scenario: 图片性能与响应式布局
- **WHEN** 用户在桌面或手机打开预览且高清图加载中或失败
- **THEN** 图片保持完整比例并按需加载，提供状态与缩略图回退，弹窗内容可滚动且无水平溢出。
