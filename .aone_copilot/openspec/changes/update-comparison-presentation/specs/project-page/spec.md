## ADDED Requirements

### Requirement: 条件图可检查
系统必须以原比例展示较大的条件图与对应动作文本，并提供桌面和手机均可关闭的放大对话框。

#### Scenario: 打开并关闭条件图
- WHEN 用户点击条件图并随后点击关闭、背景或按 Escape
- THEN 展示原比例完整图片并安全返回触发按钮，不改变点云状态。

### Requirement: 面板内基线选择
两个对比区必须在基线面板标题提供方法选择，保留当前场景、帧和视角以及原有联动、播放、点大小与放大功能。

#### Scenario: 切换基线
- WHEN 用户在当前帧选择另一个基线
- THEN 左侧加载对应方法且右侧仍为 Plan4D，过期请求不能覆盖当前状态。

### Requirement: 真实聚合案例与统一布局
新增案例必须具有可追溯且条件匹配的真实输出，保留原三个案例与按需加载；所有主要区块使用一致的响应式内容边界及居中标题。

#### Scenario: 查看新增案例
- WHEN 用户选择新场景
- THEN 加载匹配的输入、动作和方法结果，不使用替代资产，手机与桌面均无横向溢出。
